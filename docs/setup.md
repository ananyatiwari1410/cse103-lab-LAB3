# Project Setup Guide

## Requirements
- Python 3 installed
- Git installed
- Visual Studio Code

## Setup Instructions

1. Clone the repository.
2. Open the project folder in VS Code.
3. Navigate to the `src` folder.
4. Run the Python file using:

```bash
python main.py
```

## Project Structure

- `src/` – Contains the main Python source code.
- `tests/` – Contains test files.
- `docs/` – Contains project documentation.code
